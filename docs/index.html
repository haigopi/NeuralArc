Technology

Simple on the surface. Serious underneath.

Java Desktop Runtime

NeuralArc is written in Java as a high-performance desktop application built for strong local execution on your own machine. It combines responsive UI behavior and long-running strategy monitoring without pushing your workflow into a complicated cloud stack.

Performance Scales with Usage

System usage scales with how many strategies you run, how frequent your polling intervals are, and how many real-time trading events are being processed. NeuralArc uses system resources as needed for responsive performance, while still allowing you to start small.

3. Set Up Keys and Try Strategies

  • Copy your Alpaca Paper API keys, put them in Settings, and click Verify Connection.
  • To start with strategies, try Smart Picks using Diversified Leaders (Top 20).
  • Stay in paper mode until the workflow feels comfortable, then move to LIVE mode when you are ready to use real funds.

Mac Blocked the App?

  • If macOS prevents NeuralArc from installing or opening, open System Settings and go to Privacy & Security.
  • Under Security, choose Open Anyway for NeuralArc, then confirm the Open prompt.

What Happens Next

  • You begin safely in simulation mode first.
  • Once your workflow looks right, you can promote strategies to live.
